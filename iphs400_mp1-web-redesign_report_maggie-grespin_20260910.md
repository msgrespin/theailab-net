## My Changes

The primary things I changed about the course website were the aesthetics, navigation and the displaying of information. In class I was the project lead so I had already forked the course website onto my github, and I decided to keep the critique we had run in class as my foundation. To begin the redesign process I started by looking online for portfolio website designs that inspired me. One website I found was https://www.sunnypatel.net/. It spoke to me because I knew I wanted a website that was calm, elegant and also efficient at communicating information. So I started the redesign. I replaced the default serif font and the color scheme on the course website because I found them rather lackluster. The colors I chose were firstly for appearance, but I also wanted to make sure they were easy on the eyes because I often am doing IPHS homework after a long day of other work. I choose the background of (#edeef0), added a strong readable type with big, tight headings, and one muted blue accent (#2b5896) used only when necessary to communicate important information. I stuck to using no web fonts, no decoration because I wanted just system fonts and restraint as it is just a syllabus website.

Next, I want to talk about the changes I made to the site navigation. I added "call-to-action" buttons that are filled with an arrow to more easily jump to information most commonly sought out by students. I also added a "On this Page" table of contents section in the top right corner of every page (except the home). It stays visible the whole time someone is on the page. This feature highlights the important sub-heading sections so that students can always easily navigate each page. The aesthetic of these was pulled from the Sunny Patel website but tailored to fit the changes already implemented. Additionally, I added hyperlinks throughout the course site so if a major topic is referenced on one page, it will take you to the section it is referring to. Another hyperlink I added that makes this site more efficient is the ability to move to adjacent weeks in the schedule section of the course. For example, if I am in Week 4 I can easily move to Week 3 or Week 5.

Finally I want to step through the changes I made in the structure of the course information to make it more clear. I had the course dates paragraph changed into a readable table. I also reorganized the assignments page because it did not make sense to me that the rubric for MP3 and MP4 was after the Final Project introduction. I also moved the pass/fail note from the rubric MP3+4 section to its own section after MP1 and MP2. Finally I reorganized the assignments and weights table so it is clear that the first section refers to the mini-projects and the second section refers to the final project. This was important to me as I thought it was backwards that the November 13th date showed up after the November 20th date in the table. All of these changes do not impact the actual information, just how it is organized to be more readable.

As I said in the AI statement above, I directed the work but Claude Code executed it. I sourced the reference website, and worked with Claude to tailor it to the specific needs of this course. All the other sites I looked at were either too boring or too creative for a syllabus website. The Sunny Patel site was clear and confident without being overwhelming. Before Claude even started to code I reviewed its tech-spec and five judgment calls: 1) no build step or templating (keep it as-is, no magic), 2) assume theailab.net as the URL, 3) How to de-duplicate content across pages, 4) Week-title wording for clarity, and 5) Never rewrite the instructor's policy text. I approved them all and kept editing the aesthetic elements. I iterated the palette live by working with the color work screenshot Claude gave me, as to make an informative decision. Additionally, I had Claude test-first on the first three tasks (write a test, watch it fail, make the change, watch it pass, commit). I verified every commit was scoped to one task only. Finally, I went through page by page in Chrome to review and fix any mistakes I found. On the final pass we fixed minor details like the table text size, removing the header underline, shortening table of contents labels, fixing the boldness inconsistencies, and tightening spacing.

## Future Ideas

Some features I think could be useful to add to this site are more aesthetically focused. I would add a second color palette to match the system's dark mode preferences. I also was interested in adding a search tool in the top right corner, but I thought maybe all the hyperlinks were enough to easily navigate the site. The last thing I considered adding was an active highlighting tool so that the "On this Page" could highlight which section you're currently reading. However it needed JS so I deliberately didn't add it.
